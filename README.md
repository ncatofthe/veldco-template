# Veldco Template

Коммерческий шаблон сайта для гостиничного бизнеса.

Проект показывает структуру публичного сайта: главный экран, описание объекта, каталог/страницы, базовая серверная часть и подготовка к дальнейшей настройке под заказчика.

## Что внутри

- адаптивные HTML-страницы;
- базовая структура каталога;
- Node.js server;
- SQL-схема для хранения данных;
- `.env.example` для настройки окружения.

## Запуск

```bash
npm install
npm start
```

## Стек

HTML, CSS, JavaScript, Node.js, SQL.

## Статус

Шаблон использовался как основа коммерческого сайта для гостиничного объекта. В репозитории оставлены исходники и безопасные примеры настроек, без локальных зависимостей и приватных данных.
